## Project title: City of Moreton Bay Entrepreneurship & Innovation: Web Development Job Simulation on Forage 

### **Context:** Built as a part of the Moreton Bay Entrepreneurship & Innovation: Web Development Job Simulation on Forage

### **Status:** Complete

### **Project Description:**
- This Forage simulation included creating a report based on the structural analysis of different non-profit organisations. The report included identification of features and potential disruptions faced while navigating through the websites, and creating a plan on potential improvements that can be made. 
- Later in the stage, the simulation tasked with creating a userflow diagram and a sitemap diagram for a potential non-profit company’s website, using the potential improvements plan made in the report earlier. 
- The simulation’s last task involved creating a landing page for the company using HTML and CSS using a reference of the expected outcome provided. 

### **Technology Stack:**
- HTML
- CSS
- Figma
